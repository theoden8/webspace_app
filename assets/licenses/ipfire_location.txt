IPFire Location Database, as converted into Tor's GeoIP table by the
Tor Project.

The data is distributed by the IPFire Project under the Creative Commons
Attribution-ShareAlike 4.0 International licence. The Tor Project converts
it with geoip-db-tool into the table at src/config/geoip in the tor source
tree, under the same licence.

Webspace does not ship this data. When a site pins the country its Tor
traffic exits from, the device downloads the table from the Tor Project
through Tor, keeps it unmodified in the app's cache, and hands it to the
embedded Tor client so it can tell which relays are in which country.
A table that does not declare this licence in its own header is refused.
